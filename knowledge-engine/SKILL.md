# Master Upstream Knowledge Engine & NotebookLM Compiler (v2.0)

High-density upstream knowledge orchestrator connecting Google NotebookLM course clusters with universal playbook distillation in Zerops. Guarantees zero generic marketing slop by enforcing strictly mathematical, systemic extraction from course intelligence into canonical TYM (Type-YAML-Markdown) playbooks in `/var/www/baiosfera/PLAYBOOKS/`.

## Operational Contracts (Positive Guidance)

1. **Pure Upstream Grounding**: Maintain and query thematic NotebookLM clusters via `nlm` or Python API. Compile distilled universal playbooks into `/var/www/baiosfera/PLAYBOOKS/` without embedding vendor names, commercial academies, or static author identities.
2. **Deterministic System Dynamics**: Adapt extraction prompts using the MIT/Meadows System Dynamics paradigm:
   - *Iceberg Model*: Events $\to$ Patterns $\to$ Systemic Structures $\to$ Mental Models.
   - *Feedback Loops*: Reinforcing ($R$) and Balancing ($B$) causal loops.
   - *Stocks and Flows*: Accumulations, flow rates, and leverage points.
3. **Decoupled Downstream Handoff**: Delegate all brand token hydration, copy transmutations, and UI component generation to [`brand-play`](file:///var/www/zerops-astro-skills/brand-play/SKILL.md).
4. **Living Catalog Ingestion**: Scan, deduplicate, and sync course materials incrementally using `knowledge-sync push --target-cluster <name>`.
5. **Physical AST Validation**: Ensure all distilled playbooks adhere to the canonical TYM schema (`playbook_tym_contracts.ts`).
