# Research Infrastructure Manual: Remote MCPs, Quotas & Anti-AMN Guard (v9.0)

Defines active transports, quota economics, failover cascades, and physical `tool-guard.py` enforcement for the research backbone.

---

## 1. Engine Architecture & Live Transports

Five core research engines run as **vendor-hosted Streamable HTTP MCPs** (`0` local processes, `0 MB` idle RAM on `zcp`). Only the two F2 fallback search engines run lightweight ephemeral `npx` processes when called:

| Phase | Engine | Transport / Endpoint | Auth Header / Env | Local Footprint | Quota & Role |
|---|---|---|---|---|---|
| **F0** | **Engram LTM** | Local plugin `gentle-ai-engram` (SQLite + FTS5) | None | Local DB | Unlimited ($0) — Local recall |
| **F1** | **Context7** | Remote HTTP `https://mcp.context7.com/mcp` | None | **0 MB / 0 proc** | Unlimited ($0) — Canonical package docs |
| **F2 Primary** | **Exa** | Remote HTTP `https://mcp.exa.ai/mcp` | `x-api-key: $EXA_API_KEY` | **0 MB / 0 proc** | 1,000 req/mo — Code & neural search |
| **F2 Primary** | **Tavily** | Remote HTTP `https://mcp.tavily.com/mcp/` | `Authorization: Bearer $TAVILY_API_KEY` | **0 MB / 0 proc** | 1,000 req/mo — Releases, changelogs, CVEs |
| **F2+F3 Core** | **Jina AI** | Remote HTTP `https://mcp.jina.ai/v1` + `r.jina.ai`/`s.jina.ai` | `Authorization: Bearer $JINA_API_KEY` | **0 MB / 0 proc** | High token tier — **Imprescindible verbatim reader** |
| **F2+F4 Cloud** | **Firecrawl** | Remote HTTP `https://mcp.firecrawl.dev/v2/mcp` | `Authorization: Bearer $FIRECRAWL_API_KEY` | **0 MB / 0 proc** | 500 credits/mo — Developer index, crawls & SPAs |
| **F2 Fallback 1** | **Brave Search** | Stdio `npx -y @brave/brave-search-mcp-server` | `env.BRAVE_API_KEY` | On-demand | 2,000/mo, **1 req/s** — Fallback when F2 primaries fail |
| **F2 Fallback 2** | **DuckDuckGo** | Stdio `npx -y duckduckgo-mcp-server` | None | On-demand | Unlimited ($0) — Last-resort search fallback |
| **F3/F4 CLI** | **Curl / Crawl4AI / Playwright** | `run_command` / Python 3.12 (`-B`) | `$JINA_API_KEY` (optional) | Local ephemeral | Unlimited ($0) — Raw HTTP, CSS selectors, headless |
| **F4 Platform** | **Zerops Browser** | MCP `zerops` (`zerops_browser`) | Platform token | Container | Live Zerops service inspection |

> **Configuration Contract:** Antigravity CLI (`agy`) registers remote MCPs using `"serverUrl"` + `"headers"` in `/var/www/.gemini/config/mcp_config.json` (generated by `scripts/setup-browser.sh` using env-expanded keys; plaintext secrets remain outside Git). Local astrological MCPs stay disabled in `mcp_config.disabled.json` (executed strictly on demand by `oraculo/scripts/omni_engine.py`).

## 2. Failover & Credit Conservation Cascade

```text
F0: engram (mem_search / mem_context)
 └─[Miss]─► F1: context7 (resolve-library-id -> query-docs)
             └─[Web/SOTA needed]─► F2 Primary: exa / tavily / jina search_web / firecrawl_developer_search
                                    └─[429 / Error / Empty]─► F2 Fallback 1: brave (1.1s throttle)
                                                               └─[Exhausted]─► F2 Fallback 2: duckduckgo -> s.jina.ai
                                    ▼ (Canonical URLs discovered)
                                   F3 Verbatim (MANDATORY): jina read_url / r.jina.ai -> web_fetch_exa / tavily_extract / curl
                                    └─[JS/WAF blocked]─► F4: firecrawl_scrape / firecrawl_interact / crawl4ai / zerops_browser
                                                          ▼
                                   F5 Synthesis (date -u, >=2 sources) -> F6: engram mem_save
```

### Credit & Payload Discipline
1. Cap `web_fetch_exa` at `maxCharacters: 3000`; prefer `jina:read_url` or `r.jina.ai` for full markdown docs.
2. Keep `tavily_search` at `search_depth: "basic"`, `max_results: 5`, `include_raw_content: false`.
3. Enforce `>= 1.1s` delay between consecutive `brave_web_search` calls.
4. On DuckDuckGo anomaly responses (`DDG detected an anomaly`), abort DDG immediately and pivot to `jina:search_web` or `s.jina.ai` without retry loops.
5. Reserve `firecrawl_scrape` / `firecrawl_crawl` for sites where Jina Reader or local `curl`/Crawl4AI encounter Cloudflare or dynamic SPAs.

## 3. Physical Anti-AMN Enforcement (`tool-guard.py`)

The lifecycle harness in `/var/www/.bin/hooks/tool-guard.py` (`.agents/hooks.json`) physically backs `research`:
1. **`search_web` Block (`PreToolUse`):** Blocks built-in ungrounded `search_web` and routes to `context7`, `exa`, `tavily`, `jina`, `firecrawl`, or fallbacks `brave`/`duckduckgo`, or `invoke_subagent(TypeName="research")`.
2. **Phase Telemetry (`/tmp/.research_grounding_state.json`):** Records discovery vs verbatim calls across MCPs (`context7`, `exa`, `tavily`, `jina`, `firecrawl`, `brave`, `duckduckgo`) and `curl r.jina.ai`/`s.jina.ai` invocations.
3. **Subagent Wait Lock (`PreToolUse` + `Stop`):** Holds plan creation and Linear ticket creation while delegated `research` subagents remain in flight.
4. **Skill & F4 Plan Gate (`A3.5`):** Blocks mutating skills or writing final F4 plans (`/var/www/artifacts/plans/*.md`) without recent live research grounding.
5. **Anti-AMN Stop Gate (`0.5.4`):** When a prompt asks for external research, SOTA benchmarks, live documentation, or Anti-AMN verification, ensures at least one live research call AND a verbatim primary read (F3 Jina/Context7/Fetch) executed during the turn before finishing.
6. **Bounded Execution:** Run CLI probes with `timeout 10s` and `python3 -B` (`sys.dont_write_bytecode = True`).
