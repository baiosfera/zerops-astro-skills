## 2. The 8-Step Construction & Evolution Lifecycle

### Step 1: Gap Identification & Phase F2 Activation
- Identify an undocumented technology, API, package, or platform capability.
- Determine if the skill is a new build, an evolution/refactor, or an invariant audit.
- Classify the target into one of the **4 Functional Archetypes**:
  1. *Code, SDK & Framework* (e.g. `bun`, `astro`, `fastapi`, `react-19`)
  2. *Infrastructure & Platform Services* (e.g. `zcp`, `dckr`, `postgresql`, `valkey`, `nats`)
  3. *Domain Engines, REST APIs & Calculation Motors* (e.g. `vedastro`, `freeastroapi`, `astrologyapi`, `kundali`)
  4. *Cognitive, Planning, Workflow & Design Methodologies* (e.g. `planner`, `research`, `cohalo`, `chroma`, `fontgen`)

### Step 2: Epistemic Inflow & Research Ingestion
- Ground all parameters, CLI flags, ports, and schemas in verbatim documentation.
- When delegating to a research subagent (`invoke_subagent` with `typeName: "research"`), inject the mandatory prompt contract from [`assets/subagent_meta_prompt_template.md`](file:///var/www/.agents/skills/docu/assets/subagent_meta_prompt_template.md).
- Follow the ingestion guidelines in [`assets/research_ingestion_protocol.md`](file:///var/www/.agents/skills/docu/assets/research_ingestion_protocol.md).

### Step 3: Multi-Page Recursive Infiltration & Report Ingestion
- Discover documentation sitemap / table of contents.
- Crawl child reference URLs verbatim using Jina Reader, Context7, or local scrapers.
- **Snippet is Not Evidence**: Always read full-page verbatim documentation.
- **Mandatory Staging Report Ingestion & Unbundling**: Read `/var/www/artifacts/<target>_research_report.md` generated by `research`. Systematically unbundle 100% of classes, method signatures, return types, configuration parameters, and failure modes across `references/usage.md` (and `references/infra.md` when applicable) without lossy compression.

### Step 4: Normative Directory Scaffolding & Mode Selection
- **Mode A: Full Synthesis & Scaffolding Mode (via `skill-creator`)**:
  Applies `skill-creator` standards: clean frontmatter with quoted description and triggers, compact router (`SKILL.md` <= 550 tokens), progressive disclosure to `references/` and `assets/`, decision tables, minimal copy-paste examples. Execute [`assets/skill_scaffold.py`](file:///var/www/.agents/skills/docu/assets/skill_scaffold.py) with the appropriate `--archetype`:
  ```bash
  python3 assets/skill_scaffold.py <slug> "<triggers>" "<description>" --archetype <framework|infra|domain|cognitive>
  ```
- **Mode B: Incremental Patch & Refactoring Mode (via `skill-improver` + Zero Deletion + CoHaLo)**:
  If the skill already exists and requires evolution, updates, or optimization:
  1. **Pre-Audit (via `skill-improver`)**: Audit existing skill against style guide criteria (frontmatter, trigger clarity, body token budget, actionability, decision tables).
  2. **Zero Deletion / Lossless Invariant**: Never delete technical constraints, endpoints, types, or rules. Spatial-offload detail from `SKILL.md` to `references/usage.md` or `assets/`.
  3. **Positive Guidance & CoHaLo**: Eradicate legacy negative directives; convert constraints into positive deterministic contracts and physical validation scripts.
  4. **8-Node Physical Chain**: Snapshot backup in `0zcp-123/bak/skills/` -> edit -> SemVer bump -> sensor test (`*-validate.sh` exit 0) -> SSoT Drive mirror -> generator sync -> registry refresh -> `mem_save`.
- **Mode C: Certification & Invariance Mode (Anti-Churn)**: When auditing an existing skill, evaluate the 5 normative criteria defined in [`references/certification.md`](file:///var/www/.agents/skills/docu/references/certification.md). If all criteria pass with exit code 0 on the physical sensor, declare the skill `Certified Optimal / Invariant / Anti-Fragile` and preserve 0 byte modifications on disk, eliminating compulsive churn.

### Step 5: High-Density Reference Drafting (Zero Deletion Invariant)
- **`references/usage.md`**: Complete client setup, full method signature matrix, complete type definitions, production recipes, error handling tables, and domain specifications.
- **`references/infra.md`** (Platform and service workloads only): Service specs, environment variables dictionary, persistent storage paths, and lifecycle commands.

### Step 6: Executive Router Authoring (`SKILL.md`) & CoHaLo Compilation
- Author `SKILL.md` strictly within 180–450 tokens.
- Embed the compiled Fractal CoHaLo harness:
  ```markdown
  ## Critical Workflows / Execution Steps
  1. Validate parameters and consult references.
  2. Bounded Execution: Use strict timeouts (`timeout 10s`), `WaitMsBeforeAsync: 10000`, and `manage_task action="kill"`.
  3. Circuit Breaker: Limit retries to 2 attempts on HTTP 500/timeout before human escalation.
  4. Physical Sensor Attestation: Verify exit code 0 or HTTP 200.
  ```
- Use absolute clickable file links (`file:///var/www/.agents/skills/<target>/...`).
- **Anti-Artifacts Invariant**: Permanent files MUST resolve within the skill tree; avoid linking to temporary `/var/www/artifacts/` in permanent references.
