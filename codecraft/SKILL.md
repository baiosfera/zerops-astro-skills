# `codecraft` — Master Software Craftsmanship Orchestrator (v1.0)

## Activation Contract
Activate when designing deep module interfaces, implementing features test-first (TDD), diagnosing hard bugs, refactoring legacy logic, or executing changes with Organic Driven Development (ODD) rigor.

## Hard Rules & Positive Guidance
- **Pre-Flight Epistemic Gate**: Open and read matching sub-skills via canonical `file:///` URIs before authoring code.
- **Organic Driven Development (ODD)**: Execute changes through the 5-phase organic loop: bounded exploration, interface design, surgical TDD, proportional verification, and work-unit commits.
- **Dual-Domain Invariant**:
  * Code & Scripts: Context-bounded, physical syntax validation (`python3 -m py_compile`, `bash -n`), tests exit 0. No token limits on code.
  * Prompts & Skills: Positive guidance, Dual-RAG progressive disclosure, router `SKILL.md` <= 480 words.
- **Surgical Discipline**: Adhere to `karpathy-guidelines`. Avoid speculative abstractions or unrequested rewrites.
- **Evidence Before Assertions**: Claim success only after verifying physical commands with exit code 0 (`verification-before-completion`).
- **Lossless References**: Consult [`references/usage.md`](file:///var/www/.agents/skills/codecraft/references/usage.md) and [`references/infra.md`](file:///var/www/.agents/skills/codecraft/references/infra.md).
